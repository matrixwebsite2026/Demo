MATRIX FINAL MULTI-PAGE WEBSITE
================================
Entry point: index.html
Pages: Home, Solutions, About, Waterproofing & ESG Standards, Projects, Contact / Book an Audit, Offices, and six individual product pages.

Design:
- Red exterior / blue inner boundary identity
- Minimal premium corporate layout
- Responsive desktop/tablet/mobile styles
- Architectural image crops embedded directly in each HTML file
- Shared navigation and footer links across all pages
- Product cards link to individual product pages
- Contact form currently prepares an enquiry email using the visitor's email application; it does NOT submit to a server.

Before public production deployment:
1. Connect the enquiry form to an approved CRM/form endpoint and test spam protection, consent, and delivery.
2. Confirm all claims, warranty details, project names/images, and approved content with MATRIX.
3. Replace mockup-derived image crops with licensed high-resolution original project photography where available.
4. Confirm privacy policy/terms destinations and official office addresses.
5. Test on real browsers and mobile devices, accessibility, SEO metadata, analytics, and performance.
6. Confirm all image and content rights and any required image credits.
